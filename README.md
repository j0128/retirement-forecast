# 退休收益預測

Windows 桌面程式（tkinter），輸入年齡、收入、投資帳戶、貸款、勞退與勞保，預測逐年淨資產與退休後資金可撐多久。幣別：新台幣。

## 取得 exe
到 GitHub **Actions → build-exe → 最新一次執行 → Artifacts → RetirementForecast-exe** 下載。
設定會自動存成 exe 旁的 `retirement_settings.json`（內含個人財務資料，已列入 .gitignore，請勿上傳）。

## 本機執行
    python main.py
    python -m unittest discover -s tests

## 模型假設
- 以月為單位模擬，名目金額；通膨會推高支出，並另外顯示「今日購買力」淨資產。
- 投資帳戶：月複利；每個帳戶可設多個「投資時間段」（以年齡計，各段有自己的報酬率與每月增額）。最後一段結束後沿用其報酬率並停止加碼；退休後不再加碼。
- 每月現金流 = 稅後薪資 − 生活支出 − 貸款 − 投資加碼；結餘進活存，不足先動用活存、再依序動用各帳戶。
- 退休後：每年年初依清單順序（投資帳戶 → 退休金帳戶 → 活存）提領，把「退休生活費帳戶」補足到設定金額（預設 180 萬，今日幣值、隨通膨調整）。年金、退休金月領先進此帳戶，生活費與貸款從此帳戶支出；不足時臨時提領，全部耗盡時記錄「資產耗盡年齡」。
- 貸款：固定月扣款（餘額以剩餘應付總額估算）或本息平均攤還（輸入本金、利率，算出月付與真實餘額）。
- 退休金專戶（勞退新制、私校退撫儲金等）：提繳比例、工資上限皆可調整；請領年齡不早於退休年齡。一次領會在請領時轉入「退休金帳戶」，可另設投資時間段；月領則以年金公式分攤到預期壽命。
- 勞保老年年金：取「年資×(投保薪資×0.775%+3000)」與「年資×投保薪資×1.55%」較高者，提前/延後每年 ∓4%（最多 5 年）；不含 CPI 調整。
- 雇主另給的退休金：退休當月一次入帳，與專戶一次領的金額合併轉入「退休金帳戶」（不另計稅）。
- 薪水以「實領月薪」輸入，每月預扣所得稅另列為稅款準備金；每年 5 月依「年度結算有效稅率」（課稅所得 = 薪資 + 應稅額外收入）結算上一年度，多退少補。不處理級距、免稅額與扣除額。
- 額外收入、保險皆有起訖年齡；保險可設滿期金，於領取年齡入帳到指定帳戶。
- 不動產市值計入淨資產（另列「不含不動產」）；可設定出售年齡，扣交易成本與綁定貸款餘額後入帳；不含房地合一稅。
- 醫療費用：自起算年齡（預設 70 歲）每月加計，並以高於通膨的幅度成長。
- 三情境：悲觀 / 基準 / 樂觀 = 投資帳戶（含退休金帳戶）報酬率 ∓ 設定的百分點，圖表疊加比較。
- 年終獎金以實領月薪的月數計，於指定月份發放並計入課稅所得。
- 其他固定支出（子女教育、孝親費…）、一次性收支（買車、出國、遺產…）皆可設定年齡；一次性收入可指定入帳帳戶。
- 財務指標：4% 法則可持續月提領、固定月收入覆蓋率、緊急預備金月數、目前每月現金流。
- 「匯出報告」產生可列印（瀏覽器另存 PDF）的 HTML 報告。
- 僅供估算，非投資或稅務建議。
