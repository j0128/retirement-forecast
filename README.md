# 退休收益預測

Windows 桌面程式（tkinter），輸入年齡、收入、投資帳戶、貸款、勞退與勞保，預測逐年淨資產與退休後資金可撐多久。幣別：新台幣。

## 取得 exe
到 GitHub **Actions → build-exe → 最新一次執行 → Artifacts → RetirementForecast-exe** 下載。
設定會自動存成 exe 旁的 `retirement_settings.json`（內含個人財務資料，已列入 .gitignore，請勿上傳）。

## 本機執行
    python main.py
    python -m unittest discover -s tests

## 模型假設
- 以月為單位模擬，名目金額；通膨會推高支出，並另外顯示「今日購買力」淨資產。
- 投資帳戶：月複利；投資年限期滿或退休後停止加碼，之後只複利。
- 每月現金流 = 稅後薪資 − 生活支出 − 貸款 − 投資加碼；結餘進活存，不足先動用活存、再依序動用各帳戶。
- 退休後的缺口同樣依序提領；全部耗盡時記錄「資產耗盡年齡」。
- 貸款：固定月扣款（餘額以剩餘應付總額估算）或本息平均攤還（輸入本金、利率，算出月付與真實餘額）。
- 勞退新制：雇主 6% + 自提（提繳工資上限 150,000），帳戶複利；月領以年金公式分攤到預期壽命，或一次領。
- 勞保老年年金：取「年資×(投保薪資×0.775%+3000)」與「年資×投保薪資×1.55%」較高者，提前/延後每年 ∓4%（最多 5 年）；不含 CPI 調整。
- 所得稅以有效稅率簡化，不處理級距、免稅額與扣除額。僅供估算，非投資或稅務建議。
